# 메뉴 견본 — 공통 레이아웃 1단계

- 작성일: 2026-11-26
- 상태: 승인됨

## 배경 / 문제

목사님께 화면설계서 확인을 요청했지만, 비전문가라 문서를 어떻게 봐야 할지 모르겠다고 하셔서 확인 없이 넘어갔다. 메뉴는 모든 화면의 뼈대라 개발이 더 진행되기 전에 확인받아야 한다. 문서 대신 **stg.rtf.or.kr에서 직접 눌러 보는 메뉴 견본**을 보여 드리고, 메뉴 이름 · 순서 · 어느 메뉴에 무엇이 들어가는지를 확인받는다.

헤더 · 메뉴 · 푸터 · 서브 화면 틀은 실제로 쓸 코드로 만들어, 확인 후 버리지 않고 공통 레이아웃 2단계로 이어 간다.

## 목표

- 화면설계서 3장의 메뉴 전체를 stg에서 실제로 눌러 오갈 수 있게 한다 (화면 19개)
- 헤더 · PC 드롭다운 · 모바일 메뉴 패널 · 푸터 · 서브 화면 틀을 실제 코드로 만든다
- PC 드롭다운과 모바일 패널의 동작 · 애니메이션을 서울포럼(seoulforum.kr)과 같게 맞춘다
- 화면 안 내용은 이름표를 붙인 회색 박스로 자리만 잡아, 화면마다 무엇이 들어가는지 보여 준다
- 운영(rtf.or.kr)은 지금처럼 준비 중 화면만 보이게 둔다

## 비목표 (이번에 하지 않는 것)

- Supabase 연결, 실제 데이터, 로그인 · 회원가입 · 검색 기능 — 로그인 · 회원가입 · 🔍는 "준비 중입니다." 알림만
- 글 상세 · 글쓰기 · 마이페이지 · 비밀번호 찾기 화면 — 메뉴에서 바로 가는 화면이 아님
- 회차 선택 · 필터 · 페이지 번호 · 다운로드 등 버튼 동작 — 박스로만 표시
- 홈 히어로 위 투명 헤더와 스크롤 효과 (서울포럼에는 있음) — 2단계
- 서브 비주얼 배경 사진 — 사진이 없어 자리만 표시
- 화면별 디자인 다듬기 — 2단계 이후
- 새 화면의 sitemap 등록 — 실제 내용이 생길 때
- 유튜브 링크, 대표 이메일 표기 — 자료 대기
- 화면 안 확인 질문 상자 — 검토했지만 뺌. 확인은 직접 여쭤본다 (대화에서 확정)
- 대메뉴 하위 화면을 공통 빈 화면 하나로 처리하는 안 — 검토했지만 뺌. 무엇이 들어가는지 확인받을 수 없음

## 사용자 시나리오

1. **목사님(휴대폰 360px)** → stg.rtf.or.kr 접속 → ☰를 눌러 메뉴 패널이 오른쪽에서 전체 화면으로 밀려 들어오는지, '포럼 소개'를 누르면 그 줄이 강조되며 하위 메뉴가 펼쳐지고 다른 대메뉴를 누르면 앞의 것은 닫히는지 확인 → '연혁'을 눌러 연혁 화면으로 이동하는지 확인
2. **목사님(휴대폰)** → 연혁 화면에서 하위 메뉴 탭을 가로로 넘겨 '섬기는 사람들'로 이동 → 현재 탭이 굵게 · 밑줄로 표시되는지, 화면 안 회색 박스 이름으로 무엇이 들어갈지 알 수 있는지 확인
3. **목사님(PC 1280px)** → 대메뉴 '연구·자료'에 마우스를 올림 → 헤더가 0.4초에 늘어나며 다섯 대메뉴의 하위 메뉴가 모두 보이고, 마우스를 올린 열이 연한 바탕으로 강조되는지 확인 → '자료실'을 눌러 이동
4. **키보드 사용자(PC)** → Tab으로 대메뉴에 포커스 → 드롭다운이 열리고 하위 메뉴까지 Tab으로 이동되는지, Esc로 닫히는지 확인
5. **방문자** → 헤더의 🔍 · 로그인, 모바일 패널의 로그인 · 회원가입을 누름 → "준비 중입니다." 알림이 뜨는지 확인
6. **방문자** → 헤더 · 모바일 패널 · 푸터의 네이버 밴드를 누름 → 새 탭에서 `https://band.us/band/57603243`이 열리는지 확인
7. **'동작 줄이기'를 켠 사용자** → 드롭다운과 모바일 패널을 엶 → 애니메이션 없이 바로 열리는지 확인
8. **운영 방문자** → rtf.or.kr 접속 → 지금처럼 준비 중 화면만 보이는지 확인

## 설계 요약

**화면과 주소** (대화에서 확정 — 화면설계서 3장 URL 규칙)

| 대메뉴      | 화면                                                                                                                                               |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 홈          | `/`                                                                                                                                                |
| 포럼 소개   | `/about`(인사말) · `/about/confession`(설립 목적·신앙고백) · `/about/history`(연혁) · `/about/people`(섬기는 사람들) · `/about/contact`(오시는 길) |
| 제28차 포럼 | `/forum`(포럼 개요) · `/forum/program` · `/forum/speakers` · `/forum/venue`                                                                        |
| 연구·자료   | `/research/papers` · `/research/columns` · `/research/archive`                                                                                     |
| 아카이브    | `/archive`(지난 포럼) · `/archive/videos`                                                                                                          |
| 커뮤니티    | `/board/notice` · `/board/qna` · 네이버 밴드↗(새 탭)                                                                                               |
| 약관(푸터)  | `/terms` · `/privacy`                                                                                                                              |

- 대메뉴 주소는 첫 하위 메뉴 화면이다
- 메뉴 구성은 상수 하나(`shared/config/navigation.ts`)에 두고 헤더 · 모바일 패널 · 하위 메뉴 탭 · 푸터가 함께 쓴다. 목사님 의견으로 이름 · 순서가 바뀌면 이 파일만 고친다
- '이번 포럼' 대메뉴는 **"제28차 포럼"으로 고정**한다. 회차는 상수 하나로 두고 DB 연결 때 바꾼다 (대화에서 확정. 다음 포럼이 제28차인지는 목사님께 확인)
- 로그인 · 회원가입 · 통합검색은 화면을 만들지 않고 누르면 `alert("준비 중입니다.")` (대화에서 확정)

**헤더 (5-1)** (대화에서 확정)

- 로고 · PC 대메뉴 · 밴드↗ · 🔍 · 로그인. 높이 모바일 64px, PC 96px (`DESIGN.md`)
- 이번 단계에서는 항상 흰 바탕으로 상단에 고정한다
- 현재 위치한 대메뉴는 포럼 블루로 표시한다

**PC 드롭다운 — 서울포럼 동작 기준** (대화에서 확정, 2026-11-26 실측)

- 대메뉴 하나에 마우스를 올리거나 키보드로 포커스하면 헤더 아래가 늘어나며 **모든 대메뉴의 하위 메뉴가 각 대메뉴 아래 세로 줄로** 한 번에 보인다
- 늘어나는 시간 0.4초, 하위 메뉴 글자가 나타나는 시간 0.2초
- 마우스를 올린 열은 대메뉴부터 하위 메뉴 끝까지 `muted` 바탕, 대메뉴 글자는 `primary`
- 하위 메뉴에 마우스를 올리면 굵게 + 밑줄
- 서울포럼에 없는 것을 더한다 — 키보드 포커스로 열림, Esc로 닫힘
- shadcn `NavigationMenu`는 하나씩 펼치는 방식이라 맞지 않아 CSS(`group-hover` · `focus-within`)로 직접 만든다
- 색 · 모양은 `DESIGN.md`를 따른다 (서울포럼의 밝은 파랑 대신 포럼 블루, 모서리 0). 서울포럼의 코드 · 이미지는 가져오지 않는다

**모바일 메뉴 패널 (5-2) — 서울포럼 동작 기준** (대화에서 확정)

- ☰를 누르면 화면 전체를 덮는 흰 패널이 오른쪽에서 0.4초에 밀려 들어온다. ✕로 닫는다
- 대메뉴는 위아래 구분선이 있는 목록, 오른쪽에 ⌄ 화살표
- 대메뉴를 누르면 그 줄이 `primary` 바탕 · 흰 글자가 되고 화살표가 ⌃로 바뀌며 하위 메뉴가 펼쳐진다. 한 번에 하나만 열리고, 펼침은 애니메이션 없이 바로 열린다
- 화면설계서 5-2에 따라 위에 [로그인] [회원가입](준비 중 알림), 아래에 네이버 밴드↗를 둔다 (서울포럼에는 없음)
- shadcn `Sheet`(전체 화면, 오른쪽, 0.4초)와 `Accordion`(한 번에 하나, 높이 애니메이션 끔)을 쓴다. 패널이 열려 있는 동안 포커스가 패널 밖으로 나가지 않는다
- '동작 줄이기' 설정이면 드롭다운과 패널 모두 애니메이션 없이 바로 열린다

**푸터 (5-3)** (대화에서 확정)

- 링크: 개인정보처리방침 · 이용약관 · 오시는 길 · 질문하기(`/board/qna`)
- 기관명 · 사무총장 · 주소 · 전화 · 네이버 밴드. 이메일 · 유튜브는 자료 대기라 뺀다
- `footer` 먹색 바탕, 흰색 단색 로고
- 기관 정보는 기존 `shared/config/site.ts` 상수를 쓴다

**서브 화면 틀 (5-4)** (대화에서 확정)

- ① 서브 비주얼: `muted` 띠에 대메뉴 이름을 크게, 한쪽에 작게 "배경 사진 자리 — 대메뉴마다 1장". 높이 모바일 140px, PC 240px
- ② 하위 메뉴 탭: 현재 화면은 굵게 · 밑줄 · `aria-current="page"`, 모바일은 가로 스크롤
- ③ 페이지 제목. 제28차 포럼 화면은 제목 옆에 [제28차 ▾] 회차 선택 자리를 박스로
- 대메뉴마다 `src/app` 아래 레이아웃을 두어 서브 화면 틀을 한 번만 적용한다. 루트 `layout.tsx`와 `/coming-soon`은 건드리지 않는다
